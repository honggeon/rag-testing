# 红烧肉家常做法

## 食材准备

五花肉五百克、冰糖三十克、生抽两勺、老抽一勺、料酒两勺、
姜片三片、八角两颗、桂皮一小段、葱结一个。

## 制作步骤

1. 五花肉切三厘米见方的块，冷水下锅焯水，撇去浮沫后捞出洗净。
2. 锅中放少许油，下冰糖小火炒至枣红色糖色。
3. 倒入肉块翻炒上色，加入姜片、八角、桂皮炒香。
4. 加料酒、生抽、老抽翻炒均匀，倒入没过肉块的热水。
5. 大火烧开后转小火焖煮五十分钟，大火收汁至浓稠即可。

## 关键提示

炒糖色时火不能大，否则发苦。本菜谱与任何知识库检索测试无关，
仅作为"无关文档"用于交叉污染检测。菜谱标记词：ragtest-recipe。
